# Relógio Neon

Este projeto é um relógio digital moderno, com visual futurista e estilo neon em fundo preto. O objetivo é demonstrar a manipulação de data e hora em JavaScript, combinando funcionalidade com design visual impactante.

## Funcionalidades

- Exibição da hora em tempo real
- Mostrar a data e o dia da semana
- Visual em preto com brilho neon
- Animações suaves em CSS para um efeito tecnológico
- Interface simples e responsiva

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo

Criar uma interface visualmente atrativa e funcional para estudo de desenvolvimento web, com foco em design moderno e interatividade.
